## 🧠 Sobre mim

Analista de **Dados Pleno em Prevenção a Fraudes no PagBank** (São Paulo). Trabalho entre os dados e a operação: regras de risco no Crivo e no Feedzai Pulse, SQL, Python, ETLs e monitoramentos. Analista no cargo, engenheiro na prática — construo o pipeline inteiro e deixo documentado para quem vem depois.

Fora do expediente, desenvolvo o **Myncellium**: minha própria stack de agentes de IA em Node.js, com plano → aprovação → evidência.

- 🏦 **3 anos** em prevenção a fraudes (adquirência, banking e onboarding)
- 📈 **2 promoções** em menos de 2 anos: estagiário → Jr → Pleno
- 🤖 **~14 milhões de tokens** processados por **US$ 0,39** de API no Myncellium (vs ~US$ 94 na API do GPT)
- 📜 **62 certificados**: TruIQ Crivo (TransUnion) + 61 cursos da DIO
- 🌎 São Paulo, Brasil
